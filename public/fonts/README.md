# Portfolio display font

`portfolio-og.ttf` is a 600-style share-image subset of Noto Serif SC. It contains
only the glyphs used by the current portfolio, project, blog, and article share
cards. Next.js `ImageResponse` requires TTF, OTF, or WOFF, so this file is not
served by the visible page and does not enter the browser performance budget.

- Source family: Noto Serif SC
